ADAS Fleet Intelligence API Contract (v2)

1. Registration

POST/api/v1/employer/register

Description: Registers a new employer fleet account.

Request Body (JSON):

  • employer_name (string)
  • phone_number (string)
  • email (string, valid email)
  • country (string)
  • password (string, min 8 chars)

Response (200 OK):

  • status (string)
  • message (string)

POST/api/v1/driver/register

Description: Registers a new independent driver account.

Request Body (JSON):

  • driver_name (string)
  • phone_number (string)
  • national_id (string)
  • license_expiration_date (string, YYYY-MM-DD)
  • email (string, valid email)
  • password (string, min 8 chars)

Response (200 OK):

  • status (string)
  • message (string)
  • driver_id (integer)

2. Authentication

POST/api/v1/employer/login

Description: Authenticates an employer and returns a JWT.

Request Body (Form Data):

  • username (string, email address)
  • password (string)

Response (200 OK):

  • access_token (string)
  • token_type (string, defaults to "bearer")
  • employer_id (integer)

POST/api/v1/driver/login

Description: Authenticates a driver and returns a JWT.

Request Body (Form Data):

  • username (string, email address)
  • password (string)

Response (200 OK):

  • access_token (string)
  • token_type (string, defaults to "bearer")
  • driver_id (integer)

3. Dashboard - Employer

Requires Employer JWT in Authorization: Bearer <token> header

GET/api/v1/dashboard/employer/drivers

Description: Retrieves all drivers in a fleet, sorted by safety scores.

Response (200 OK):

  • ranked_employees (array of objects):
    • employee (string)
    • email (string)
    • national_id (string)
    • role (string)
    • safety_score (float)
    • trips (integer)
    • licenseExpiration (string, date)
    • rank (integer)

GET/api/v1/dashboard/employer/devices

Description: Retrieves specific hardware device details for the fleet.

Response (200 OK):

  • devices (array of objects):
    • serial_number (string)
    • manufacturing_date (string, date)
    • active_employee_email (string | null)

GET/api/v1/dashboard/employer/fleet-analysis

Description: Aggregated charts and summary for the entire fleet.

Query Parameters:

  • timeframe (string, required: "hour", "day", or "month")
  • target_date (string, optional: e.g., "YYYY-MM-DD")
  • threshold (float, required: default 0.75)

Response (200 OK):

  • summary_report (object):
    • total_employees (integer)
    • top_driver (string | null)
    • needs_attention (string | null)
    • total_trips (integer)
    • total_drive_time_mins (float)
    • total_risky_drive_time_mins (float)
    • alerts (integer - calculated directly from raw unaggregated events)
    • avg_driver_score (float)
    • avg_road_score (float)
    • avg_risk_score (float)
    • percentile_95th (float - uses robust statistical ceiling)
    • event_ratio (float)
    • significance (string - e.g., "Significantly High Risk (p < 0.05)" derived via Z-Test)
  • trend_chart (array of objects: timestamp string, score float. Automatically 0.0-padded for frontend rendering).
  • distractions_split (array of objects: name string, value_percentage float, duration_minutes float)

GET/api/v1/dashboard/employer/drivers/{driver_email}/details

Description: Analytical charts and history for a specific driver.

Path Parameters: driver_email (string)

Query Parameters: timeframe (string), target_date (string | optional), threshold (float)

Response (200 OK):

  • driver_info (object: name, national_id, status)
  • summary_report (object: strictly mirrors the fleet-analysis summary keys above)
  • analysis (object containing trend_chart and distractions_split arrays)

4. Dashboard - Driver

Requires Driver JWT in Authorization: Bearer <token> header

GET/api/v1/dashboard/driver/details

Description: Profile info, stats, charts, and pending requests for the logged-in driver.

Query Parameters: timeframe (string), target_date (string | optional), threshold (float)

Response (200 OK):

  • profile (object: driver_name, email, active_employers array)
  • summary_report (object: strictly mirrors the fleet-analysis summary keys above)
  • analysis (object: trend_chart, distractions_split)
  • pending_requests (array of objects: request_id, employer_name)

POST/api/v1/dashboard/driver/start-trip

Description: Assigns the driver to a specific car and starts trip sequence.

Request Body (JSON):

  • serial_number (string)

Response (200 OK):

  • status (string)
  • device_id (integer)
  • driver_id (integer)

POST/api/v1/dashboard/driver/end-trip

Description: Unassigns the driver from the vehicle.

Request Body (JSON):

  • serial_number (string)

Response (200 OK):

  • status (string)

POST/api/v1/dashboard/driver/calibration/request-snapshot

Description: Driver clicks 'Capture Image' on web app to wake up the camera.

Request Body (JSON):

  • serial_number (string)

Response (200 OK):

  • status (string)

GET/api/v1/dashboard/driver/calibration/snapshot/{serial_number}

Description: Fetches the latest camera frame for the frontend UI.

Path Parameters: serial_number (string)

Response (200 OK):

  • snapshot_base64 (string)
  • detections (array)

POST/api/v1/dashboard/driver/calibration/save

Description: Saves lane nodes and physical attributes configured from the driver UI.

Request Body (JSON):

  • serial_number (string)
  • calibration (object)
    • mounting_height (float)
    • focal_distance (float)
    • ego_lane_nodes (array of exactly 4 objects: x float, y float)
    • selected_bbox (object: x1, y1, x2, y2 floats)

Response (200 OK):

  • status (string)

5. Employment

POST/api/v1/employment/employer/request

Description: Invites an independent driver to join a fleet. (Employer Auth)

Request Body (JSON):

  • driver_email (string)

Response (200 OK):

  • status (string)
  • message (string)
  • request_id (integer)

POST/api/v1/employment/driver/requests/{request_id}/respond

Description: Driver accepts or rejects an employment invitation. (Driver Auth)

Path Parameters: request_id (integer)

Request Body (JSON):

  • status (string: "Accepted" or "Rejected")

Response (200 OK):

  • status (string)
  • message (string)

DELETE/api/v1/employment/driver/sever/{employer_email}

Description: Allows a driver to resign or disconnect from a fleet using the employer's email. (Driver Auth)

Path Parameters: employer_email (string)

Response (200 OK):

  • status (string)
  • message (string)

DELETE/api/v1/employment/employer/sever/{driver_email}

Description: Allows an employer to remove a driver from their fleet using the driver's email. (Employer Auth)

Path Parameters: driver_email (string)

Response (200 OK):

  • status (string)
  • message (string)

6. Hardware Management & Integration

POST/api/v1/internal/devices/provision

Description: Registers a newly manufactured device. (No Auth required currently)

Request Body (JSON):

  • serial_number (string)
  • manufacturing_date (string, date)
  • activation_pin (string)

Response (200 OK):

  • status (string)
  • message (string)

POST/api/v1/dashboard/employer/devices/claim

Description: Claims a device for an employer's fleet. (Employer Auth)

Request Body (JSON):

  • serial_number (string)
  • activation_pin (string)

Response (200 OK):

  • status (string)
  • message (string)

POST/api/v1/readings/batch

Description: Hardware uploads a batch file containing telemetry. (Hardware Auth)

Headers: x-api-key (string, required)

Request Body (JSON Array of Objects):

  • device_id (integer)
  • driver_id (integer)
  • timestamp (string, ISO datetime, UTC)
  • driver_score, road_score, risk_score, urgency, proximity (float)
  • road_objects_classes (string)
  • gps_coordinates (string | null)
  • driver_distraction_distribution (object with 10 variables using 1/0 one-hot flags for current state)

Response (200 OK):

  • status (string)
  • message (string)

GET/api/v1/hardware/status

Description: Hardware polls for commands or an active driver. (Hardware Auth)

Headers: x-api-key (string, required)

Response (200 OK):

  • status (string: "waiting", "capture_snapshot", "fetch_calibration", "active")
  • driver_id (integer | optional)
  • device_id (integer | optional)

POST/api/v1/hardware/calibration/snapshot

Description: Hardware uploads an image frame and bounding boxes. (Hardware Auth)

Headers: x-api-key (string, required)

Request Body (JSON):

  • snapshot_base64 (string)
  • detections (array of objects: x1, y1, x2, y2 all floats)

Response (200 OK):

  • status (string)

GET/api/v1/hardware/calibration

Description: Hardware downloads the calibration JSON to save locally. (Hardware Auth)

Headers: x-api-key (string, required)

Response (200 OK): Returns the exact JSON calibration object saved.

  • status (string)
  • message (string)

DELETE/api/v1/device/{device_id}

Path Parameters: device_id (integer)

Response (200 OK):

  • status (string)
  • message (string)

DELETE/api/v1/employer/{employer_id}

Path Parameters: employer_id (integer)

Response (200 OK):

  • status (string)
  • message (string)

DELETE/api/v1/driver/{driver_id}

Path Parameters: driver_id (integer)

Response (200 OK):

  • status (string)
  • message (string)

DELETE/api/v1/requests/all

Response (200 OK):

  • status (string)
  • message (string)

GET/api/v1/readings/{device_id}/{driver_id}/all

Description: Fetches every single raw reading for a given device and driver pair.

Path Parameters: device_id (integer), driver_id (integer)

Response (200 OK): Array of all raw reading objects matching the ReadingCreate schema + timestamp as ISO string.

GET/api/v1/readings/{device_id}/{driver_id}/range

Description: NEW: Fetches readings within a specific ISO datetime window.

Path Parameters: device_id (integer), driver_id (integer)

Query Parameters: start_time (string, ISO datetime), end_time (string, ISO datetime)

Response (200 OK): Array of all raw reading objects within the range matching the ReadingCreate schema + timestamp as ISO string.

DELETE/api/v1/readings/{device_id}/{driver_id}/range

Description: Deletes readings within a specific datetime window.

Path Parameters: device_id (integer), driver_id (integer)

Query Parameters: start_time (string, ISO datetime), end_time (string, ISO datetime)

Response (200 OK):

  • status (string)
  • message (string)
